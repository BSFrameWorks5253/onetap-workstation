=== What's New ===
* Resilient Title Adder Video Rendering Pipeline: Bulletproof multi-stage rendering with automatic GPU-to-CPU failover, ensuring client computers without dedicated GPUs or with conflicting drivers render seamlessly.
* Automatic FFmpeg Binary Discovery: Dynamic environment path resolver for FFmpeg and FFprobe binaries across WinGet, Scoop, Chocolatey, and standard installation roots.
* Stream-Specific Cover Art Synthesis: Explicitly scoped stream mapping and pixel format conversions for thumbnail cover art embedding without stalling the main video stream.

=== Bugs Fixed ===
* Resolved Title Adder Render Not Starting: Eliminated global frame limit (-vframes:v:1 1) on attached picture streams that prematurely terminated full-length video encoding.
* Fixed Filtergraph Incompatibility: Removed -hwaccel auto from video input streams, preventing dxva2/cuda hardware surface conflicts with CPU software scale/pad filters.
* Fixed FFprobe Metadata Skip: Added dual format/stream duration parsing and seamless fallback to ffmpeg -i when ffprobe is missing or returns N/A for stream duration.
* Fixed GPU Encode Abort: Automatically catches GPU encoder crashes (NVENC, QSV, AMF) and executes immediate in-flight retry using libx264 (CPU).

=== Improvements ===
* Comprehensive Stderr Error Logging: Captured and surfaced granular FFmpeg stderr diagnostics directly to the UI activity log and dynamic status displays.
* Clean Retry Engine: Automatically removes incomplete or corrupted partial outputs before launching fallback retries.
* Multi-Target Setup Installer: NSIS and Inno Setup integration for single-click installation and portable distribution.
