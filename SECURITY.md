# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| v26.10.x | :white_check_mark: |
| < v26.9.0 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability or exploit within **UniDesk Studio**, please do NOT open a public issue.

Instead, please report security concerns privately:
- **Email**: `bs.framework5253@gmail.com`
- **Subject**: `[SECURITY VULNERABILITY] UniDesk Studio`

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Potential impact on workstation security or file system.

We will acknowledge receipt within 48 hours and work with you to patch the issue before any public disclosure.
