Can I use Uni Desk alongside my existing Premiere Pro workflows? +

Microsoft Store Integration & Publishing Guide

How this app is configured for Microsoft Partner Center

Uni Desk supports two publication pathways on the Microsoft Store:

1

Direct Win32 (.EXE) URL Submission (Recommended)

Microsoft Partner Center allows submitting traditional desktop .exe installers hosted directly on your website HTTPS URL. When users install via Microsoft Store, Windows automatically downloads this latest executable and runs silent installation using /S flag.

Installer URL: https://bsframework.com/onetap/downloads/Uni_Desk_Setup_V26.10.0.exe
Silent Switch: /S
2

Native MSIX Package Store Submission

Alternatively, the application can be built into a signed .msix container using electron-builder --win appx or the Windows MSIX Packaging Tool for standard sandboxed distribution.

3

Microsoft Store Product ID Configuration

Once approved in Microsoft Partner Center, update CONFIG.msStoreId in website/app.js with your assigned Product ID (e.g., 9NXXXXXXXXXX) to enable automatic 1-click deep-linking.
