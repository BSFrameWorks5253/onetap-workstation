# Microsoft Store Submission Guide for Uni Desk

This step-by-step guide explains how to publish **Uni Desk** to the **Microsoft Store** and connect it to your new download website.

---

## 🚀 Option 1: Direct Win32 (.EXE) Installer URL (Recommended & Fastest)

Microsoft allows publishing existing Win32 `.exe` installers directly to the Microsoft Store without rewriting code or packaging into MSIX containers.

### Step 1: Register on Microsoft Partner Center
1. Go to [Microsoft Partner Center](https://partner.microsoft.com/dashboard).
2. Sign in with your Microsoft Account.
3. Enroll in the **Windows & Xbox** developer program:
   - Individual Account: ~$19 USD (one-time fee)
   - Company Account: ~$99 USD (one-time fee)

### Step 2: Reserve Your App Name
1. In Partner Center dashboard, click **Apps & games** > **New product**.
2. Select **Windows app** > **EXE or MSI app**.
3. Enter your app name: `Uni Desk` (or `Uni Desk Workstation`) and click **Reserve product name**.

### Step 3: Configure Package & Installer Settings
Fill in the submission details:
- **Installer Type**: `EXE (NSIS)`
- **Download URL**: Enter the direct HTTPS URL where your installer is hosted (e.g. `https://bsframework.com/onetap/Uni%20Desk_Setup_V26.10.0.exe` or your GitHub Releases download link).
- **Silent Install Arguments**:
  ```text
  /S
  ```
  *(Uni Desk uses NSIS installer generated by electron-builder, where `/S` performs a silent background install).*
- **Silent Uninstall Arguments**:
  ```text
  /S
  ```
- **Install Return Codes**:
  - `0` = Success
  - `3010` = Success (Restart Required)
- **Architectures**: Select `x64` (64-bit).
- **Minimum OS Version**: `Windows 10, version 1809 (Build 17763)` or later.

### Step 4: Add Store Listing & Media Assets
- **Short Description**:
  > Next-generation media automation workstation for Adobe Premiere Pro, Media Encoder, batch file processing, and studio archiving.
- **Detailed Description**:
  > Uni Desk transforms Adobe Premiere Pro & Media Encoder into an autonomous batch powerhouse. Features include zero-click Domino pipelines (Media Encoder -> Title Adder -> Converter), sub-millisecond sequence XML locators, smart Nikah and ceremony detection with multi-track ripple placement, and high-integrity archive reconciliation.
- **Keywords**: `Premiere Pro`, `Media Encoder`, `Automation`, `Video Editing`, `Converter`, `Studio Archive`.
- **Logos & Screenshots**:
  - App Logo: `website/assets/logo.png` (or 300×300 / 512×512 PNG)
  - Promotional Screenshots: 1920×1080 screenshots of Uni Desk tabs (Dashboard, Title Adder, Converter, Archive Vault).
- **Privacy Policy URL**: `https://bsframework.com/privacy`
- **Support Contact**: `support@bsframework.com`

### Step 5: Submit for Certification
- Click **Submit to the Store**.
- Microsoft's automated scanner tests the installer download and silent install switches.
- Review typically takes 24–48 hours.

---

## 📦 Option 2: Build a Packaged MSIX / APPX Container (Optional)

If you prefer a signed MSIX package rather than an installer URL:

1. In `package.json`, `electron-builder` supports target `appx`:
   ```bash
   npx electron-builder --win appx
   ```
2. Upload the generated `.appx` or `.msix` file directly to Partner Center.

---

## 🔗 Step 6: Link Your Microsoft Store ID in the Website

Once Microsoft approves your app, Partner Center will provide your unique **Product ID** (a 12-character alphanumeric string like `9NXXXXXXXXXX`).

Update `website/app.js`:
```javascript
microsoftStore: {
  productId: "YOUR_12_CHAR_PRODUCT_ID", // e.g. 9NABC123DEF4
  webUrl: "https://apps.microsoft.com/detail/YOUR_12_CHAR_PRODUCT_ID?mode=direct",
  deepLink: "ms-windows-store://pdp/?productid=YOUR_12_CHAR_PRODUCT_ID"
}
```

Now:
- Clicking **"Get it from Microsoft Store"** on your website will immediately launch the **Microsoft Store** app directly on Windows 10/11!
- Users can choose either the direct `.exe` installer or the Microsoft Store version.
